# 三级分级学习体系设计(小班 / 中班 / 大班)

- 日期:2026-08-31
- 分支:`feature/grade-levels`
- 状态:待大王审阅

## 1. 背景与目标

当前软件 132 字 / 19 单元平铺,无难度分级。本次按年龄引入三级学习体系:

| 阶段 | 名称 | 年龄 | 累计字量 | 定位 |
|------|------|------|---------|------|
| stage 1 | 小班 · 启蒙乐园 | 3-4 岁 | 150 | 象形字 + 生活高频字,建立字形-实物对应 |
| stage 2 | 中班 · 成长乐园 | 4-5 岁 | 300 | 生活场景扩展 + 简单虚词,建立字义关联 |
| stage 3 | 大班 · 衔接乐园 | 5-6 岁 | 600 | 一年级高频字 + 结构规律,幼小衔接 |

依据:《3-6岁识字学习计划》(用户提供 docx)+ 网络调研结论(100/300/800 为幼小衔接培训界通行标准;大班对标部编版一年级上册字表是业界共识,洪恩/古古识字等同做法)。

## 2. 总体结构

```
阶段(stage) ──包含──► 单元(unit)──包含──► 字(char)
   │                     │
   │                     └─ 玩法轮次:识字卡 + 2~3 个练习游戏
   └─ 每阶段末尾 1 个复习单元(本阶段已学字混排出题)
```

- 阶段内单元顺序解锁(沿用现有机制)
- 通关上一阶段全部单元(含复习单元)解锁下一阶段
- 每阶段目标字量为**精确值**(150/300/600),进度条与测试断言都以此为准

## 3. 单元规划

### 3.1 现有 19 单元归类(编号不变)

| 归入阶段 | 现有单元 | 字数小计 |
|---------|---------|---------|
| 小班 | 1 太阳和月亮、2 农场的小伙伴、3 我的身体、4 美丽花园、5 汉字小达人、6 一家人、14 动物园、18 数字乐园、19 象形字乐园 | 55 |
| 中班 | 7 我的家、8 好吃的、9 动一动、10 穿戴上、11 出门去、12 颜色、13 大自然、15 一天四季、16 方位、17 小身体与文具 | 77 |

**决策:现有 unit 1-19 编号保持不变,新单元从 20 追加。** 进度按 levelId 落盘,不重排则老进度零迁移;地图展示顺序由 STAGES 定义中的单元列表决定,与编号无关(编号不展示)。

### 3.2 新增单元(编号 20+)

> 字量口径:每阶段**阶段池**字数 = 该阶段全部单元的字数之和;累计 = 前序阶段池相加。
> 小班池 150(现有 55 + 新增 95)、中班池 150(现有 77 + 新增 73)、大班池 300(全新),累计 600。

| 阶段 | 新增字数 | 新增单元(主题示例,编制时可微调) |
|------|---------|--------------------------------|
| 小班 | 95 | 好吃的水果、天气我知道、动物朋友 2、动作歌(站坐爬飞游)、大小多少 |
| 中班 | 73 | 幼儿园里(校园师生课本)、心情颜色(高兴害怕喜欢)、高矮多少(量词状态)、来去开关(方位动作)、我的一天 |
| 大班 | 300 | 以部编版一年级上册字表为主体分主题:天地人、口耳目、日月水火、对韵歌、四季、影子、大小多少、小书包、日月明、升国旗、影子朋友、方位歌,补充现代高频(电视机电网络) |

- 小班新增字**全部选有图字**(有 OpenMoji 对应)
- 中班引入少量无图虚词(的、是、有、在等,走纯字玩法)
- 大班以一年级字表为主,无图字比例最高
- 复习单元各 1 个,排每阶段单元列表末尾,主题名"复习时间"

### 3.3 单元规模

- 小班单元 5-8 字/单元(3-4 岁注意力短)
- 中班单元 8-12 字/单元
- 大班单元 12-20 字/单元(5-6 岁课时可到 20-30 分钟)

## 4. 数据层设计

### 4.1 characters.js

- 每字增加 `stage: 1|2|3` 字段(与 unit 所属阶段一致,测试断言校验)
- 新增 468 字(95 + 73 + 300),字段结构与现状一致
- **无图字:`emojiCode` 置 `null`**。emojiCode 现状仅素材生成脚本使用、运行时不读,复用该字段做"有无图"标志零成本;选择原则:优先单字本义 emoji,其次组词 emoji(如 学→学校🏫),两者皆无则置 null
- 新增导出 `byStage(stage)`(按阶段过滤)

### 4.2 levels.js

新增 `STAGES` 定义:

```js
const STAGES = [
  { id: 1, name: '小班', subtitle: '启蒙乐园', age: '3-4岁', units: [1, 2, 3, 4, 5, 6, 14, 18, 19, /*新20+*/, /*复习*/] },
  { id: 2, name: '中班', subtitle: '成长乐园', age: '4-5岁', units: [7, 8, 9, 10, 11, 12, 13, 15, 16, 17, /*新*/, /*复习*/] },
  { id: 3, name: '大班', subtitle: '衔接乐园', age: '5-6岁', units: [/*全新*/, /*复习*/] },
]
```

- `generateUnit(unit)` 按 stage 参数化(玩法池 / optCap / 练习轮次数,见第 5 节)
- 现有 LEGACY 单元 1-5 的轮次定义**原样保留**(体验已验证)
- 复习单元:`{ id, theme: '复习时间', type: 'review', stage: N, rounds: [...] }`,rounds 由生成函数产出(玩法组合固定、出题运行时随机)

## 5. 玩法与难度配置(游戏与阶段关联)

共 8 个游戏,按认知负荷分配到阶段:

| 阶段 | 游戏池 | optCap(干扰项) | 练习轮次 | 理由 |
|------|--------|---------------|---------|------|
| 小班 | 识字卡、看图选字、听音选字、找一找 | 3 | 2 | 3-4 岁反应慢,不进打地鼠(限时)与连连看(多对记忆) |
| 中班 | 全部 8 种轮换(维持现有 5 套模板机制) | 3→4 | 2 | 4-5 岁黄金期全面接触 |
| 大班 | 全部 8 种,偏重找一找/翻牌/打地鼠/连连看 | 5 | 3 | 衔接期负荷拉满,对齐一年级 |
| 复习单元 | 本阶段游戏池综合混排 | 随阶段 | 2-3 | 混排即复习(艾宾浩斯理念) |

> 阶段游戏池约束只针对**新生成单元**;现有 LEGACY 单元 1-5 轮次原样保留(其中单元 3 的 findall、单元 5 的 bubble 虽不在小班池,体验已验证,不动)。

### 无图字玩法适配(engine.js)

- 新增判断:字池中 `emojiCode != null` 的字才可进入 pic2char / match / link 轮次
- 单元含无图字时:图玩法目标字从有图子集抽取;有图字不足时该轮自动替换为纯字玩法(sound2char / findall / bubble / whack)
- **现有 8 个玩法组件零改动**,适配全部在出题层

## 6. 复习单元机制

- 位置:STAGES[N].units 末尾,每阶段 1 个,共 3 个
- 出题字池:`byStage(N)` 全阶段字(复习单元本身 id 下无直接挂字,`byUnit` 取不到,出题层按 `type==='review'` 切换为 `byStage(stage)` 取池)
- 轮次:识字卡(快速过一遍抽样字)+ 2-3 个混合练习,玩法从本阶段池选
- 通关条件与普通单元一致(拿任意星),算入阶段解锁条件

## 7. 进度与解锁

**存储结构完全不动**(key `hanzi-paradise-v1`、`stars`、`unlockedLevel` 原样),阶段解锁不落盘、全部派生:

```
stageUnlocked(s)   = s === 1
                   || STAGES[s-1].units 每个单元 stars[id] >= 1
isUnlocked(unitId) = stageUnlocked(stageOf(unitId))
                   && 该单元在 STAGES[s].units 中 ≤ 第一个未通关单元的位置
```

- `progress.js` 重写 `isUnlocked` 为派生实现,新增 `stageUnlocked` / `stageProgress`
- `completeLevel` 不变(星级落盘)
- 老进度天然兼容:已通关单元照常亮星,未解锁单元按新规则重新判定(中班单元在小班通关前锁定,正是本需求期望的行为变化)

## 12. 决策记录

| 决策 | 理由 |
|------|------|
| 单元追加不重排 | 老进度零迁移、零兼容代码 |
| 阶段解锁用派生不落盘 | 存储不动,单一事实来源是 stars |
| 阶段字量定精确值(150/300/600) | 进度条分母与测试断言需要确定值 |
| emojiCode=null 表示无图字 | 复用现有字段,运行时零成本判断 |
| 现有 LEGACY 单元 1-5 轮次不动 | 体验已验证,尊重现状 |
| 大班对标部编版一年级上册字表 | 幼小衔接业界共识,家长可感知 |
